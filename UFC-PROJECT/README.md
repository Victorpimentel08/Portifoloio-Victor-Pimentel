# UFC Project

Site educacional não oficial sobre UFC, organizado em pastas.

## Como executar
Abra `index.html` no navegador. Não precisa instalar nada.

## Estrutura
- `pages/`: páginas HTML
- `css/`: estilos e responsividade
- `js/`: scripts e dados de exemplo
- `assets/`: pastas para imagens, ícones e fontes

**Observação:** os dados de exemplo não representam rankings ou agenda atualizados.
